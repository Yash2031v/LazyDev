Ollama Setup Guide (Local-First Theme)

LazyDev runs completely offline using local open-weight models managed by Ollama. When Ollama is not running, core developer tools and file analysis remain accessible.

1
Install Ollama

Download from official source: https://ollama.com/download/windows

2
Pull a Recommended Model

Open PowerShell and run: ollama pull qwen2.5-coder:7b or ollama pull llama3.2:3b

3
Verify Service

Ensure Ollama is running in background. Click Refresh Status above to auto-detect.
